## How to present (12–15 minutes + demo)

1. Open the `.pptx`. Full screen.
2. Slides 1–13: pitch (about 7 minutes).
3. Slide 14: live app at `https://localhost:7117` (about 8 minutes). `DEMO-SCRIPT.md`.
4. Slides 15–17: fine print, ask, questions.

Adobe Acrobat accessibility checker (presenter-run): generated school reports passed; reading / screen order is correct. Record: `evidence/test-results/adobe-acrobat-accessibility-check.md`. Not a veraPDF, PAC, or NVDA pack.

Do not treat the Knowledge Assistant as the calculator. Do not name professional associations.
